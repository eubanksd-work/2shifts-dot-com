# Logos

The Second Shift mark: a circle with its second half filled, amber dot at the center. Ink (#1c1a17) on transparent for light grounds, paper (#f5f1ea) on transparent for dark grounds; the dot is always signal #f2b35c. Avatars carry their own ground. Wordmarks set "Second Shift" in Libre Baskerville 400 beside the mark with a 12px gap. Minimum size 24px. Do not redraw, recolor, rotate, or enclose.
