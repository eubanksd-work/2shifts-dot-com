The pill button in two weights: solid ink for the one primary action on a screen, outlined for everything else. Height 44px in the header, 52px as a hero call to action, 50px on inverse bands; horizontal padding 20-28px; label in the `small` style (Public Sans 500, 15-16px). Solid hover shifts the fill to `accent`; outlined hover fills with `ink` and inverts the label. On `surface-inverse` the solid button uses `ink-inverse` as its fill. Never two solid buttons side by side, never an icon-only button, never a shadow. The consumer provides the label and the href; buttons are links (`<a>`) unless they submit a form.
